In last months, we took steps to formalise utPLSQL and to give it a legal home under utPSLQL Development Labs Ltd. 
With this being almost complete, it is now time to open utPLSQL for sponsorship that will allow for sustained development of this great framework.

utPLSQL remains free to use and open source (Apache 2.0). 


<!-- more -->

Sponsorship is a way to collect funds required to allow for work on: and new features and support for new Oracle capabilities, compatibility updates, documentation, issue triage, hosting.

## What is available

- **Organization sponsorship** from 100 EUR / month, with recognition on utplsql.org, GitHub and the framework README
- **Commercial support** with priority triage, a named contact and private consultation hours
- **Consulting, training and problem-solving** for teams adopting or scaling utPLSQL
- **Individual sponsorship** through GitHub Sponsors, any amount

Sponsorship does not buy influence over the roadmap, and the project stays free for everyone.

Details are on the [Sponsorship page](../../../sponsorship.md).
