![utPLSQL - Testing Framework for PL/SQL](assets/utPLSQL-testing-framework-transparent.png)

The ultimate unit testing framework for Oracle PL/SQL — free, open-source, and inspired by the xUnit family (JUnit, NUnit, etc.).

Write and run tests directly in PL/SQL, integrate with your CI/CD pipeline, and get clear, actionable results every build.
